# 1. Preflight steps

Es necesario seguir estos pasos antes de poder tener acceso y contribuir al
proyecto. Somos tan fuertes como nuestro eslabón más débil, así que la
seguridad es primordial. No quiero que me hackeen la org porque alguien la
cagó xD.

- [ ] 1. Set up an authenticator app. Recommendation: [Google Authenticator](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2&hl=en_US&pli=1)
- [ ] 2. Set up a password manager. Recommendation: [Bitwarden](https://play.google.com/store/apps/details?id=com.x8bit.bitwarden)
- [ ] 3. Set up browser integration for your password manager. Recommendation: [Bitwarden extension](https://chromewebstore.google.com/detail/bitwarden-password-manage/nngceckbapebfimnlniiiahkandclblb?browser=brave)
