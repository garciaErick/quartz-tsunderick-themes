### Version Control

- [GitHub Desktop](https://desktop.github.com/) - Focus on what matters instead
  of fighting with Git. Whether you're new to Git or a seasoned user, GitHub
  Desktop simplifies your development workflow.
- [lazygit](https://github.com/jesseduffield/lazygit) - this is the best git
  client imo but its exclusively a TUI so use Github desktop if you are not yet
  comfortable in the terminal
![[lazygit.png]]
- [GitHub Cli](https://cli.github.com/)
