first contribution". Work through the two steps below in order — first secure
your accounts, then set up your environment.

## 2. Setup your environment

Developers and designers set up their tools a little differently: devs clone
the repo with the Git CLI and install pre-commit hooks, while designers can do
(almost) everything through GitHub Desktop and the Godot editor. Pick the guide
that matches your role:

- [[2-dev-environment-setup]] — for developers
- [[2-designer-environment-setup]] — for designers

Whichever path you take, one rule applies to **everyone**: do your work on your
personal branch (`tsunderick`, `robomario`, `mean-bean`, `azva01`, …) and
contribute through a Pull Request. **Never commit directly to `main`** — it's
the shared source of truth for the whole team, and direct commits make
everyone's life harder.
